# Otaku Planner — application Android

Ton planning anime et scans, dans ta poche : ta liste, les sorties de la semaine
sur les plateformes légales, et une alerte à la sortie de chaque épisode de tes séries.

**Site :** [otaku-planner.com](https://otaku-planner.com)

## Télécharger

👉 **[Télécharger la dernière version (APK)](https://github.com/TwinsDev-soft/otaku-planner-app/releases/latest/download/otaku-planner.apk)**

Toutes les versions : [Releases](https://github.com/TwinsDev-soft/otaku-planner-app/releases)

## Installer

1. Télécharge `otaku-planner.apk` sur ton téléphone Android (Android 6 ou plus récent).
2. Ouvre le fichier. Si Android bloque l'installation, touche **Paramètres** et
   autorise cette source, puis reviens en arrière et touche **Installer**.
3. Si Google Play Protect affiche un avertissement : « Plus de détails » →
   **« Installer quand même »** (normal pour une app hors Play Store).
4. Connecte-toi avec ton compte Otaku Planner (e-mail ou Google).

Les mises à jour s'installent par-dessus l'ancienne version, sans rien perdre.

## iPhone / iPad

Pas de fichier à télécharger : ouvre [otaku-planner.com](https://otaku-planner.com)
dans Safari → bouton **Partager** → **« Sur l'écran d'accueil »**.

## Vérifier le fichier (facultatif)

Chaque version publie l'empreinte SHA-256 de l'APK (`otaku-planner.apk.sha256`).
